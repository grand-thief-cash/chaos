## 三十一、验收标准

Phase 1 完成至少满足：

1. 能从 phoenixA 获取 Artemis 下载的研报记录。
2. 能从 MinIO 读取 PDF。
3. 能使用 pikepdf 在内存中解除 PDF owner permission/内容提取限制，不生成本地临时 PDF 或第二份 MinIO 对象。
4. 能将整份 PDF 提交 Qwen3-14B，不依赖 Chunking。
5. 格式错误时能携带校验错误完整打回重生成。
6. Qwen3-14B 能输出符合 Schema 的实体、关系、量化 Claim 和观点。
7. 能区分事实、公司披露、管理层计划和分析师观点。
8. 每个 Claim/View 都有最小 evidence quote 和合法 page number/null。
9. 能创建可选 sample size 的 Discovery Run。
10. Sample 能对每个候选 report type 形成可读率、知识产出、Evidence 质量和启用建议；生产只消费 Published Semantic YAML 中启用的类型。
11. 能在 cthulhu 审核 Semantic Proposal 和确认生产 report type。
12. 能发布、下载并加载不可变 Semantic YAML。
13. 申万、已获取东财和已发现券商行业术语具有完整 Crosswalk 处理结果。
14. Crosswalk 默认由模型自动解析并通过 Coverage/Conflict/Cycle 校验，不要求人工逐条批准；cthulhu 能展示最终质量并支持异常 Override。
15. 能以 security_registry 初始化 A 股实体。
16. 能解析研报中新出现的海外公司和非上市公司。
17. 不能确定的实体不会错误进入 Graph。
18. 未知 predicate 能进入 Semantic Proposal Review。
19. 标准化 Claim 能持久化。
20. Atlas 能经 phoenixA Graph API 从有效 Claim 构建和重建 Neo4j，且不直接使用 Bolt。
21. cthulhu 能审核、监控、查看 Graph 和使用 Query Agent。
22. 能查询公司产品、上下游、竞争者、材料和技术。
23. Query Agent 只能通过受控工具查询。
24. Query Agent 能区分事实和分析师观点。
25. Event、Impact、Embedding 和高级 PDF fallback 未被混入主抽取链路。
