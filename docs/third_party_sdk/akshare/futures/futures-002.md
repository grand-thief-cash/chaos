描述: 玄田数据-核心数据

限量: 单次返回指定 symbol 的所有历史数据

|--------|-----|-----------------------------------------------|
| symbol | str | symbol="外三元"; choice of {"外三元", "内三元", "土杂猪"} |

输出参数

| 名称    | 类型      | 描述 |
|-------|---------|----|
| date  | object  | -  |
| value | float64 | -  |

接口示例

```python
import akshare as ak
```

### 生猪市场价格指数

接口: index_hog_spot_price

目标地址: https://hqb.nxin.com/pigindex/index.shtml

描述: 行情宝-生猪市场价格指数

限量: 单次返回所有数据

输入参数

| 名称  | 类型  | 描述  |
|-----|-----|-----|
| -   | -   | -   |

输出参数

| 名称     | 类型      | 描述         |
|--------|---------|------------|
| 日期     | object  | -          |
| 指数     | float64 | -          |
| 4个月均线  | float64 | -          |
